# 21 Savage without authentication
A hands-on opportunity to build and develop full-stack applications while strengthening coding and debugging skills. This older codebase provides plenty of opportunities to troubleshoot, improve functionality, and gain practical development experience.

## How to navigate
Visit the Deployed Site: Navigate to the live application and view the login page.\
Log In / Sign Up: Create an account or log in to access the message board.\
Submit Messages: Use the message board to post messages, which will automatically appear in the list through backend functionality.\
Like & Dislike Messages: Use the thumbs-up and thumbs-down buttons to increase or decrease each message's like count.\
Delete Messages: Remove messages from the board using the delete option.

## Features
Frontend: HTML, CSS
Backend: Node.js, express, MongoDB

## Installation

1. Clone repo
2. run `npm install`

## Usage

1. run `npm run savage`
2. Navigate to `localhost:3000`
